# 杉田夢生 ポートフォリオサイト

杉田夢生（営業支援・営業代行）の実績紹介サイト。「名刺代わり」に商談前へURLを一つ渡し、信頼性を補強することを目的とした1ページの静的サイトです。

- 公開URL: `https://yorisoi-yumeki.github.io/`
- 技術構成: 素のHTML / CSS / JavaScript（ビルド不要）
- ホスティング: GitHub Pages（`main`ブランチ / ルートから配信）

## ローカルで確認する

ビルド不要なので、`index.html` をブラウザで直接開くだけで確認できます。

```bash
open index.html   # macOS の場合
# もしくは VS Code の Live Server 拡張などを使ってください
```

## ① 写真の差し替え

現在はプレースホルダー画像（イラストアイコン）が、ヒーロー上部の小さなバッジと「ちょっとした自己紹介」セクションの大きな写真枠の2箇所に表示されています。**コードの編集もファイル名の変更も不要**で、そのままドラッグ&ドロップするだけで自動的に切り替わります。

1. 以下のURLを開く： https://github.com/yorisoi-yumeki/yorisoi-yumeki.github.io/upload/main/assets/img
2. パソコン内の顔写真ファイルを、画面中央の枠にそのままドラッグ&ドロップする（スマホで撮った写真そのままのファイル名でOKです）
3. 下にスクロールして緑色の「Commit changes」ボタンを押す
4. 数分待つと（GitHub Pagesの再デプロイ後）、上記2箇所の写真が自動的に差し替わります

   仕組み：ページの読み込み時にJavaScriptがGitHubの公開API経由で `assets/img/` フォルダの中身を確認し、写真ファイル（jpg/jpeg/png/webp/gif、`ogp.png`は除く）を見つけたら自動的にそれを表示します。ファイル名は問いません。複数の写真ファイルを置いた場合は、そのうちの1つ（先に見つかったもの）が使われます。迷う場合はファイル名を `profile.jpg` にしていただくと、これまで通り確実に1枚だけが使われます。
   （念のための補足：この自動検出はGitHubの公開APIへの読み込みリクエストに依存するため、アクセスが集中した場合などにごく稀に反映されないことがあります。その場合も数秒後の再読み込みで直ります。）

5. LINEやメールでURLを共有した際のプレビュー画像（OGP画像）にも自分の写真を使いたい場合は、下記「⑤ OGPバナー画像の差し替え」も参照してください（こちらは別画像として用意する想定です）。

## ② メールアドレスの差し替え

サイト上のメールアドレスは仮の値（`contact@example.com`）になっています。サイト専用の新規Gmailアドレスなどを取得したら、`index.html` 内の以下2箇所を実際のアドレスに書き換えてください（`<!-- TODO -->` コメントの直後にあります）。

- ヘッダー（ヒーロー）内の「メールで連絡する」ボタン
- ページ下部の「ご連絡はこちらから」セクション

`mailto:` の部分とボタンのラベル（表示テキスト）、両方を新しいアドレスに合わせて書き換えてください。

## ③ GitHub Pagesの公開設定

Claudeが自動で有効化できなかった場合のみ、以下を手動で行ってください（1分程度）。

1. リポジトリの「Settings」タブを開く
2. 左メニューの「Pages」を開く
3. 「Build and deployment」の「Source」を **Deploy from a branch** にする
4. Branch を **main** / **/(root)** にして「Save」
5. 数分後に `https://yorisoi-yumeki.github.io/` でアクセスできるようになります

## ④ 「周囲からの声」の追加・公開（対応済み）

第三者から一言メッセージを集めるための専用ページ `voice-form.html` を用意済みです。「周囲からの声」セクションに常時表示される「一言メッセージを届ける ✎」ボタンからアクセスできます。

見た目は完全にこのサイト独自のデザインのフォームですが、送信するとバックグラウンドでGoogleフォームの回答送信エンドポイントへ直接データを送ります（画面遷移なし）。回答は通常のGoogleフォーム回答と同様に、[フォームに紐づくGoogleスプレッドシート](https://forms.gle/v8dnvnhX8GUVzTMP7)（フォーム編集画面の「回答」タブ）へ自動集計されます。

**フォームの質問項目を変更したい場合**（質問の追加・削除・選択肢の変更など）:

1. [フォームの編集画面](https://forms.gle/v8dnvnhX8GUVzTMP7) で質問を編集する
2. 質問を**追加・削除**した場合（文言だけの編集や既存の選択肢の増減は不要）、その質問の内部ID（`entry.12345678`のような番号）を確認する必要があります
   - フォーム編集画面右上の「⋮」→「フォームに事前入力する」→ 各質問に分かりやすい値（質問名など）を入力 →「リンクを取得」
   - 生成されたURLの中に `entry.xxxxx=値` という形で各質問のIDが並んでいるので、そこから該当する質問のIDを確認する
3. `assets/js/voice-form.js` 内の `ENTRY_IDS` を新しいIDに更新し、`voice-form.html` 側のフォーム項目（ラジオボタン・チェックボックスの選択肢文言など）も実際のフォームと一致するように更新する

質問の**文言や選択肢を編集するだけ**（削除して作り直すのでなければ）の場合は、`entry` IDは変わらないため、`voice-form.html` 内の該当する選択肢テキストを書き換えるだけで反映できます。

### サイトへの反映方法

1. `assets/js/testimonials.js` を開く
2. `TESTIMONIALS` 配列に、掲載してよいと判断した推薦文を1件追加する

   ```js
   { quote: "商談の場でいつも的確に本質を突いた提案をしてくださいました。", name: "山田 太郎", company: "株式会社サンプル" }
   ```

   - お名前・会社名が未回答の場合は `name` を `"匿名"`、`company` を `""` のままにしてください
3. 推薦文が **2〜3件以上** たまったら、同じファイル内の

   ```js
   var SHOW_TESTIMONIALS = false;
   ```

   を

   ```js
   var SHOW_TESTIMONIALS = true;
   ```

   に書き換えてください。これで「周囲からの声」セクションが公開されます（`false`のままだとセクション自体が非表示になります）。

入力するテキストはそのまま画面に表示されます（HTMLタグとして実行されることはない安全な実装になっています）ので、貼り付けるだけで反映できます。

## ⑤ OGPバナー画像の差し替え（対応済み）

LINEやメールでURLを共有した際のリンクプレビュー画像（OGP画像）は、Canvaで作成したバナーを `assets/img/ogp.png`（1200×630px）として反映済みです。`index.html` の `og:image` / `twitter:image` もこの画像を参照するよう設定してあるため、追加の作業は不要です。

デザイン（氏名・キャッチコピー・数字など）を今後調整したい場合は、以下のCanvaデザインを編集してください。

1. 以下のCanvaデザインを開く： https://www.canva.com/d/PH02Ijmu5zQ48qE
2. 内容（氏名・キャッチコピー・数字など）を必要に応じて調整
3. 「共有」→「ダウンロード」からPNG形式でダウンロード（推奨サイズ: 1200×630px）
4. GitHubのリポジトリ画面から `assets/img/` フォルダを開き、`ogp.png` を「Add file → Upload files」で上書きアップロード
