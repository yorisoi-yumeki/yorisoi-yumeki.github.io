# negi720-portfolio

杉田夢生（営業代行フリーランス）の実績紹介サイト。「名刺代わり」に商談前へURLを一つ渡し、信頼性を補強することを目的とした1ページの静的サイトです。

- 公開URL: `https://negi720-ui.github.io/negi720-portfolio/`
- 技術構成: 素のHTML / CSS / JavaScript（ビルド不要）
- ホスティング: GitHub Pages（`main`ブランチ / ルートから配信）

## ローカルで確認する

ビルド不要なので、`index.html` をブラウザで直接開くだけで確認できます。

```bash
open index.html   # macOS の場合
# もしくは VS Code の Live Server 拡張などを使ってください
```

## ① 写真の差し替え

現在はプレースホルダー画像（`assets/img/profile-placeholder.svg`）が表示されています。

1. ご自身の顔写真を用意する（正方形に近い構図、800px程度、WebPまたはJPEG形式に圧縮したものを推奨）
2. GitHubのリポジトリ画面から `assets/img/` フォルダを開き、「Add file → Upload files」で写真をアップロードする（ファイル名は `profile.jpg` を推奨）
3. `index.html` 内の以下の1行を書き換える（`<!-- TODO: 写真差し替え手順 -->` というコメントの直後にあります）

   ```html
   <img src="assets/img/profile-placeholder.svg" alt="杉田夢生の写真">
   ```
   ↓
   ```html
   <img src="assets/img/profile.jpg" alt="杉田夢生の写真">
   ```

4. 併せて `<head>` 内の `og:image` / `twitter:image` のパスも `assets/img/profile.jpg` に書き換えると、LINEやメールでURLを共有した際のプレビュー画像にも反映されます。

## ② メールアドレスの差し替え

サイト上のメールアドレスは仮の値（`contact@example.com`）になっています。サイト専用の新規Gmailアドレスなどを取得したら、`index.html` 内の以下2箇所を実際のアドレスに書き換えてください（`<!-- TODO: メールアドレス差し替え -->` というコメントの直後にあります）。

- ヘッダー（ヒーロー）内の「メールで連絡する」ボタン
- ページ下部の「ご連絡はこちらから」セクション

`mailto:` の部分とボタンのラベル（表示テキスト）、両方を新しいアドレスに合わせて書き換えてください。

## ③ GitHub Pagesの公開設定

Claudeが自動で有効化できなかった場合のみ、以下を手動で行ってください（1分程度）。

1. リポジトリの「Settings」タブを開く
2. 左メニューの「Pages」を開く
3. 「Build and deployment」の「Source」を **Deploy from a branch** にする
4. Branch を **main** / **/(root)** にして「Save」
5. 数分後に `https://negi720-ui.github.io/negi720-portfolio/` でアクセスできるようになります

## ④ 「お客様の声」の追加・公開

第三者から届く推薦文は、Googleフォームで収集し、届いたものを本人が選んで手動でサイトに反映する運用です。

### Googleフォームの作成手順

1. [Google フォーム](https://forms.google.com) で新規フォームを作成
2. 以下の4問を設定する

   - **Q1：どのような関わりでしたか？**（ラジオボタン・単一選択）
     選択肢：商談・提案を受けた／プロジェクトで協業した／上司・部下だった／同僚だった／その他
   - **Q2：良かった点は？**（チェックボックス・複数選択）
     選択肢：深いヒアリング力／的確な提案／仕事の速さ・レスポンス／誠実さ・信頼感／巻き込み力・調整力／その他
   - **Q3：一言コメント**（記述式・任意）
     説明文に「印象的なエピソードなどがあれば教えてください」を追記
   - **Q4：お名前・会社名**（記述式・任意）
     説明文に「表示してもよい場合のみご記入ください」を追記

3. フォームの回答は自動的にGoogleスプレッドシートに集計されます
4. 完成したフォームのURLを、必要であれば「お客様の声」セクション周辺（または連絡先の下）にリンクとして追加してください

### サイトへの反映方法

1. `assets/js/testimonials.js` を開く
2. `TESTIMONIALS` 配列に、掲載してよいと判断した推薦文を1件追加する

   ```js
   { quote: "商談の場でいつも的確に本質を突いた提案をしてくださいました。", name: "山田 太郎", company: "株式会社サンプル" }
   ```

   - お名前・会社名が未回答の場合は `name` を `"匿名"`、`company` を `""` のままにしてください
3. 推薦文が **2〜3件以上** たまったら、同じファイル内の

   ```js
   var SHOW_TESTIMONIALS = false;
   ```

   を

   ```js
   var SHOW_TESTIMONIALS = true;
   ```

   に書き換えてください。これで「お客様の声」セクションが公開されます（`false`のままだとセクション自体が非表示になります）。

入力するテキストはそのまま画面に表示されます（HTMLタグとして実行されることはない安全な実装になっています）ので、貼り付けるだけで反映できます。

## ファイル構成

```
index.html               本体（1ページ）
style.css                デザイン（カラー・レイアウト定義）
assets/js/main.js        スクロール演出・チップ/経歴カードの開閉制御
assets/js/testimonials.js お客様の声のデータとON/OFF切り替え
assets/img/               写真・アイコン類
.nojekyll                 GitHub PagesのJekyll処理をスキップするための空ファイル
```
