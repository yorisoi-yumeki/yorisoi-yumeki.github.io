# 杉田夢生 ポートフォリオサイト

杉田夢生（営業支援・営業代行）の実績紹介サイト。「名刺代わり」に商談前へURLを一つ渡し、信頼性を補強することを目的とした1ページの静的サイトです。

- 公開URL: `https://yorisoi-yumeki.github.io/`
- 技術構成: 素のHTML / CSS / JavaScript（ビルド不要）
- ホスティング: GitHub Pages（`main`ブランチ / ルートから配信）

## ローカルで確認する

ビルド不要なので、`index.html` をブラウザで直接開くだけで確認できます。

```bash
open index.html   # macOS の場合
# もしくは VS Code の Live Server 拡張などを使ってください
```

## ① 写真の差し替え

現在はプレースホルダー画像（イラストアイコン）が、ヒーロー上部の小さなバッジと「ちょっとした自己紹介」セクションの大きな写真枠の2箇所に表示されています。**コードの編集もファイル名の変更も不要**で、そのままドラッグ&ドロップするだけで自動的に切り替わります。

1. 以下のURLを開く： https://github.com/yorisoi-yumeki/yorisoi-yumeki.github.io/upload/main/assets/img
2. パソコン内の顔写真ファイルを、画面中央の枠にそのままドラッグ&ドロップする（スマホで撮った写真そのままのファイル名でOKです）
3. 下にスクロールして緑色の「Commit changes」ボタンを押す
4. 数分待つと（GitHub Pagesの再デプロイ後）、上記2箇所の写真が自動的に差し替わります

   仕組み：ページの読み込み時にJavaScriptがGitHubの公開API経由で `assets/img/` フォルダの中身を確認し、写真ファイル（jpg/jpeg/png/webp/gif、`ogp.png`は除く）を見つけたら自動的にそれを表示します。ファイル名は問いません。複数の写真ファイルを置いた場合は、そのうちの1つ（先に見つかったもの）が使われます。迷う場合はファイル名を `profile.jpg` にしていただくと、これまで通り確実に1枚だけが使われます。
   （念のための補足：この自動検出はGitHubの公開APIへの読み込みリクエストに依存するため、アクセスが集中した場合などにごく稀に反映されないことがあります。その場合も数秒後の再読み込みで直ります。）

5. LINEやメールでURLを共有した際のプレビュー画像（OGP画像）にも自分の写真を使いたい場合は、下記「⑤ OGPバナー画像の差し替え」も参照してください（こちらは別画像として用意する想定です）。

## ④ 「周囲からの声」の追加・公開（対応済み）

第三者から一言メッセージを集めるための専用ページ `voice-form.html` を用意済みです。「周囲からの声」セクションに常時表示される「一言メッセージを届ける ✎」ボタンからアクセスできます。

見た目は完全にこのサイト独自のデザインのフォームですが、送信するとバックグラウンドでGoogleフォームの回答送信エンドポイントへ直接データを送ります（画面遷移なし）。回答は通常のGoogleフォーム回答と同様に、[フォームに紐づくGoogleスプレッドシート](https://forms.gle/v8dnvnhX8GUVzTMP7)（フォーム編集画面の「回答」タブ）へ自動集計されます。

**フォームの質問項目を変更したい場合**（質問の追加・削除・選択肢の変更など）:

1. [フォームの編集画面](https://forms.gle/v8dnvnhX8GUVzTMP7) で質問を編集する
2. 質問を**追加・削除**した場合（文言だけの編集や既存の選択肢の増減は不要）、その質問の内部ID（`entry.12345678`のような番号）を確認する必要があります
   - フォーム編集画面右上の「⋮」→「フォームに事前入力する」→ 各質問に分かりやすい値（質問名など）を入力 →「リンクを取得」
   - 生成されたURLの中に `entry.xxxxx=値` という形で各質問のIDが並んでいるので、そこから該当する質問のIDを確認する
3. `assets/js/voice-form.js` 内の `ENTRY_IDS` を新しいIDに更新し、`voice-form.html` 側のフォーム項目（ラジオボタン・チェックボックスの選択肢文言など）も実際のフォームと一致するように更新する

質問の**文言や選択肢を編集するだけ**（削除して作り直すのでなければ）の場合は、`entry` IDは変わらないため、`voice-form.html` 内の該当する選択肢テキストを書き換えるだけで反映できます。

### サイトへの反映方法（管理画面を使う・推奨）

届いた回答の中からサイトに載せるものを選ぶ作業は、専用の管理画面 `admin.html` から行います。Claudeへの指示もコード編集も不要で、ブラウザだけで完結します。

#### 初回だけ：自動取得の設定（Apps Script）

`admin.html` の「STEP 1」は、ボタン1つでスプレッドシートの回答を読み込めます（毎回のコピー&ペーストが不要になります）。これを使うために、最初の1回だけ以下の設定をしてください（Googleフォームのentry ID設定と同程度の手間です。以後は再設定不要）。

1. 回答が集まるGoogleスプレッドシートを開く →「拡張機能」→「Apps Script」
2. [`docs/apps-script-sheet-api.gs.txt`](docs/apps-script-sheet-api.gs.txt) の中身を全部コピーして貼り付け、保存
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選択 →「次のユーザーとして実行」は自分、「アクセスできるユーザー」は**全員**にして「デプロイ」（Googleアカウントの承認画面が出たら許可する）
4. 発行された `https://script.google.com/macros/s/xxxxx/exec` のようなURLをコピー
5. `assets/js/admin.js` をGitHub上で開く（[編集画面](https://github.com/yorisoi-yumeki/yorisoi-yumeki.github.io/edit/main/assets/js/admin.js)）→ ファイル冒頭の「★ ここだけ書き換えればOK ★」というコメントのすぐ下にある `var SHEET_API_URL = "";` の行を見つけ、`""` の中に、そのURLを貼り付けて保存
   - 同じ「SHEET_API_URL」という文字はファイル内に他にも出てきますが、書き換えるのは冒頭のこの1箇所だけです（他は値を読み取って使っているだけなので、触らないでください）
   - このAPIは「今回は掲載しないで欲しい」と回答した人のデータをあらかじめ除外して返す実装になっているため、このURL自体は公開ソースコードに含まれても実害はありません（万一URLが第三者に知られても、非公開希望者のデータは含まれません）

質問の列を追加・変更してこの並び（タイムスタンプ〜掲載について）と変わった場合は、`docs/apps-script-sheet-api.gs.txt` 内の `PUBLISH_COL` の番号を実際の列位置に合わせて修正し、Apps Script側で再度「デプロイ」→「デプロイを管理」→ 既存のデプロイを編集 → バージョン「新バージョン」で更新してください。

#### 回答を取り込んで公開する

1. `https://yorisoi-yumeki.github.io/admin.html` を開く（検索エンジンには載らない非公開ページです。ブックマーク推奨）
2. **「STEP 1: 回答を取り込む」**で「スプレッドシートから自動で取得する」を押す（上記の設定が済んでいれば、貼り付け不要でそのまま回答一覧が表示されます）
   - 「掲載について」の回答（名前付きOK／イニシャルのみ／掲載不可）に応じて、取り込むかどうかのチェックが自動でON/OFFされ、注意書きも出ます（「掲載不可」の回答は自動でチェックが外れ、そもそも自動取得の結果には出てきません）
   - 内容を確認し、掲載してよいものにチェックを入れたまま「チェックした回答を取り込む」を押すと、下の一覧に追加されます
   - 一言コメントが未入力だった回答は、その場でテキストを直接書き足せます（「良かった点」のチェック内容が参考として表示されます）
   - 自動取得がうまくいかない場合や設定前は、同じSTEP 1内の「貼り付けでも取り込めます」を開くと、従来通りコピー&ペーストでも取り込めます
3. 会社名の追加や文面の微調整をしたい場合は、**「STEP 3: 登録済み一覧」**の「編集する」、または**「STEP 2: 個別に追加・編集する」**から行えます
   - 上部の「プレビュー」で、実際にサイトでどう表示されるかをその場で確認できます
   - 一覧の▲▼で並び替え、名前横のチェックで掲載・非掲載をその場で切り替えられます（下書きにしていた項目を後から公開する場合など）
   - 「関係性」「良かった点」は取り込み時の参考情報として一覧に薄く表示されますが、サイトには出ません
4. 内容が固まったら、ページ下部の**「STEP 4」**で「コードを生成」→「コピーする」
5. 表示されているリンクから [GitHub上のtestimonials.js編集画面](https://github.com/yorisoi-yumeki/yorisoi-yumeki.github.io/edit/main/assets/js/testimonials.js) を開く（要GitHubログイン）
6. 編集画面の中身を全選択して削除し、コピーしたコードを貼り付けて、緑色の「Commit changes」ボタンを押す
7. 数分待つとサイトに反映されます

（以前は「GitHubで開いて反映する」というコピー不要のボタンを試しましたが、GitHubの仕様上、既存ファイルを新規作成画面から上書きすることはできず「A file with the same name already exists」というエラーになることが判明したため撤去しました。上記のコピー&貼り付け方式が確実です）

**補足**：`admin.html` の入力内容はブラウザのlocalStorageに保存されるだけで、どこにも自動送信されません。別の端末やブラウザ、シークレットモードでは見えないので、必ずこまめに「STEP 4」でGitHub側に保存してください。

### サイトへの反映方法（手動で直接編集する場合）

管理画面を使わず直接編集したい場合は、`assets/js/testimonials.js` を開き、`TESTIMONIALS` 配列に掲載してよいと判断した推薦文を1件追加してください。

```js
{ quote: "商談の場でいつも的確に本質を突いた提案をしてくださいました。", name: "山田 太郎", company: "株式会社サンプル" }
```

- お名前・会社名が未回答の場合は `name` を `"匿名"`、`company` を `""` のままにしてください
- 推薦文が **2〜3件以上** たまったら、同じファイル内の `var SHOW_TESTIMONIALS = false;` を `true` に書き換えてください（これで「周囲からの声」セクションが公開されます）

入力するテキストはそのまま画面に表示されます（HTMLタグとして実行されることはない安全な実装になっています）ので、貼り付けるだけで反映できます。

## ⑤ OGPバナー画像の差し替え（対応済み）

LINEやメールでURLを共有した際のリンクプレビュー画像（OGP画像）は、Canvaで作成したバナーを `assets/img/ogp.png`（1200×630px）として反映済みです。`index.html` の `og:image` / `twitter:image` もこの画像を参照するよう設定してあるため、追加の作業は不要です。

デザイン（氏名・キャッチコピー・数字など）を今後調整したい場合は、以下のCanvaデザインを編集してください。

1. 以下のCanvaデザインを開く： https://www.canva.com/d/PH02Ijmu5zQ48qE
2. 内容（氏名・キャッチコピー・数字など）を必要に応じて調整
3. 「共有」→「ダウンロード」からPNG形式でダウンロード（推奨サイズ: 1200×630px）
4. GitHubのリポジトリ画面から `assets/img/` フォルダを開き、`ogp.png` を「Add file → Upload files」で上書きアップロード

GitHubアカウント名を `negi720-ui` → `yorisoi-yumeki` に、リポジトリ名を `negi720-portfolio` → `yorisoi-yumeki.github.io` に変更済みです。公開URLは `https://yorisoi-yumeki.github.io/` になりました（`negi720` の表記は完全に消えています）。

- `assets/js/main.js` のプロフィール写真自動検出（GitHub公開API呼び出し先）

旧URL（`https://negi720-ui.github.io/negi720-portfolio/`）は、GitHubが一定期間自動リダイレクトしてくれます。
